# ریاضی ایران - بازی آموزشی دبستان

## فایل‌های آماده

این پوشه شامل تمام فایل‌های لازم برای:

1. **آپلود مستقیم در گیت‌هاب**
2. **تبدیل به اپلیکیشن اندروید (APK)**

### محتویات اصلی

- `index.html` + پوشه‌های `css/` و `js/` : بازی کامل وب
- `android-wrapper/` : پروژه اندروید آماده برای ساخت APK
- `README.md` : راهنمای کامل

### نحوه استفاده

#### برای گیت‌هاب:
کل محتوای این پوشه را در یک ریپازیتوری آپلود کنید.

#### برای APK:
پوشه `android-wrapper` را در Android Studio باز کرده و Build APK بگیرید.
(فایل‌های بازی از قبل در `assets` کپی شده‌اند.)

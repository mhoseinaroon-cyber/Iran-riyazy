# ریاضی ایران

بازی آموزشی ریاضی برای پایه‌های اول تا ششم دبستان ایران، بر اساس سرفصل‌های کتاب‌های درسی رسمی.

## ویژگی‌ها

- پوشش تمام پایه‌های دبستان (اول تا ششم)
- موضوعات بر اساس کتاب‌های ریاضی دبستان ایران (شمارش، جمع و تفریق، ضرب و تقسیم، کسر، اعشار، هندسه، اندازه‌گیری، درصد، تناسب و ...)
- بازی‌محور با عناصر بصری (نه فقط مسابقه معادلات خشک)
- طراحی مناسب موبایل و تبلت
- ذخیره پیشرفت بازیکن
- رابط کاربری فارسی و راست‌چین

## ساختار فایل‌ها

```
riazi-iran/
├── index.html          # صفحه اصلی بازی
├── css/
│   └── styles.css      # استایل‌ها
├── js/
│   ├── data.js         # داده‌های سطوح و سوالات
│   └── game.js         # منطق بازی
├── assets/             # تصاویر و آیکون‌ها
├── manifest.json       # برای PWA
└── README.md
```

## اجرای بازی

فقط فایل `index.html` را در مرورگر باز کنید. بهترین تجربه روی موبایل است.

## تبدیل به APK

### روش ۱: با استفاده از Capacitor (توصیه‌شده)

1. Node.js نصب کنید.
2. دستورات زیر را اجرا کنید:

```bash
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "ریاضی ایران" com.riazi.iran --web-dir .
npx cap add android
npx cap sync
npx cap open android
```

3. در Android Studio بیلد APK بگیرید.

### روش ۲: با Android WebView ساده

در پوشه `android-wrapper` اسکلت پروژه اندروید قرار دارد. می‌توانید آن را در Android Studio باز کرده و APK بسازید.

### روش ۳: ابزارهای آنلاین

- از سایت‌هایی مثل appsgeyser.com یا webintoapp.com استفاده کنید.
- آدرس وب بازی را وارد کنید یا فایل‌ها را آپلود کنید.

## آپلود در گیت‌هاب

1. یک ریپازیتوری جدید در GitHub بسازید.
2. تمام محتویات پوشه `riazi-iran` را آپلود کنید.
3. برای انتشار آسان، می‌توانید از GitHub Pages استفاده کنید:
   - Settings > Pages > Source: main branch / root
   - بازی در آدرس `https://username.github.io/repo-name` در دسترس خواهد بود.

## توسعه بیشتر

برای افزودن سطح جدید، فایل `js/data.js` را ویرایش کنید و سطح جدیدی به آرایه `levels` اضافه نمایید.
